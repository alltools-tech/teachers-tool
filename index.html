How to Use
  • पहले Select Subject Code चुनें; फिर Set Maximum Marks और Set Project Marks दर्ज करें।
  • जब तक किसी Subject को select नहीं करेंगे, Students Table में Obtained/Project inputs बंद रहेंगे।
  • Grand Total = उन Subjects का योग (numerator = दर्ज Obtained+Project; denominator = प्रति-subject MM (+ Project limit यदि Project दर्ज किया गया हो)). Blank subjects शामिल नहीं होंगे; 0 वैल्यू शामिल होगी।
  • Print/Export में Gender = Male/Female, Caste = SC/ST/OBC/General सही आएगा (खाली हो तो खाली)।
