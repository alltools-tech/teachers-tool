महत्वपूर्ण निर्देश
  • पहले Select Subject Code चुनें; फिर Set Maximum Marks और Set Project Marks दर्ज करें।
  • जब तक कोई Subject select नहीं होगा, Students Table में उस Subject के Obtained/प्राप्तांक और Project इनपुट बंद रहेंगे।
  • Grand Total = जिन Subjects में इनपुट है उनका योग। Project खाली हो तो केवल MM से % निकलेगा; Project भरा हो तो MM+Project limit से % निकलेगा। 0/00 वैध है; blank नहीं जोड़ा जाएगा।
  • ABS लिखने पर छात्र अनुपस्थित माना जाएगा — ग्रेड “– –” दिखेगा और काउंट अलग “ABS Students” तालिका में जोड़ा जाएगा (केवल ग्रेड समरी में)।
